# Getting started with Canvasly

Canvasly keeps your designs, comments, and version history together in a
project. Everything you create lives inside one project, and a project has its
own members and billing plan.

## Create your first project

1. Sign in at `https://app.canvasly.example`.
2. Click **New project** in the left sidebar.
3. Enter a name, for example `Marketing site`, and click **Create**.

## Invite members

Open **Settings → Members** and enter each person's email address. Members can
see every design in the project.

## Billing

Each project is billed separately. Change the plan under
**Settings → Billing**.
